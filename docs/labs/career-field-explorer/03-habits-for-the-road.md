# Lab 3: Add evidence and a privacy boundary

**Lesson:** Habits for the Road  
**Time:** 12–15 minutes  
**Starter:** `02-ai-tips-recovery.html` or the student's working file  
**Recovery:** `03-habits-for-the-road-recovery.html`

## Build

Give each field a source name, source link, and date checked. Add those fields to the
editor and show them on the card. Add a short privacy note explaining that no name is
required and edits remain on the device.

## Prompt to use with AI

> Add evidence tracking to each career field. The editor needs Source name, Source
> URL, and Date checked. Show them clearly on the card and make valid source links
> open in a new tab. Display “Source needed” when the information is missing. Add this
> rule near the tool: “No name required. Do not enter private information.” Do not
> invent a source, hide missing evidence, or send any data anywhere.

## Test before finishing

- A complete source shows its name, date, and working link.
- A missing source says “Source needed.”
- An invalid URL does not become a clickable link.
- The page does not ask for a name, email, school, address, or account.

## What this lab teaches

Students own what the app claims and share only what the task needs.
