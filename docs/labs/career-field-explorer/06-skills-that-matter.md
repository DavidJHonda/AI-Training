# Lab 6: Remove false certainty

**Lesson:** Skills That Matter  
**Time:** 12–15 minutes  
**Starter:** `05-creative-thinking-recovery.html` or the student's working file  
**Recovery:** `06-skills-that-matter-recovery.html`

## Diagnose before building

The first comparison uses labels that sound like a verdict: Strong fit, Unsure, and
Weak fit. Those labels can make limited evidence look more conclusive than it is.

## Build

Replace the labels with **Looks promising**, **Need evidence**, and **Possible
tension**. Make Need evidence the default. Add a visible rule that the table has no
total, score, or winner and that the human makes the call.

## Prompt to use with AI

> The comparison currently creates false certainty. Reframe it as an evidence
> organizer, not a career matcher. Replace Strong fit, Unsure, and Weak fit with Looks
> promising, Need evidence, and Possible tension. Make Need evidence the default for
> every new cell. Add a short visible rule: no total, score, or winner. Preserve the
> student's current selections where possible. Do not add percentages, stars, ranks,
> recommendations, or a best-match result.

## Test before finishing

- New comparison cells begin at Need evidence.
- No number, score, rank, total, winner, or recommendation appears.
- Color is not the only signal for the three states.
- The student can explain why the final decision remains theirs.

## What this lab teaches

The important move is not producing another interface. It is recognizing when a
working interface frames the problem badly and making the human call.
