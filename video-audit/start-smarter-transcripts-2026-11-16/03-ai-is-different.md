# 3. AI is Different

`course-assets/ai-is-different/ai-is-different.mp4` · 4:20 · 698 words

**[0:00]** Today's artificial intelligence behaves differently from traditional software. If you approach it expecting the same exact responses you're used to getting from your computer, you're going to end up confused. Two key differences explain why. First, AI learns patterns from examples rather than relying only on program or written rules. Second, it can work with unstructured data like everyday language, images, and messy handwriting with a lot more flexibility. Let's think about traditional software first. Imagine you're signing into Spotify, but you enter the wrong password. Should the app let you in because your guess was pretty close or maybe because your spelling was creative? No, you want it to follow a strict rule. Let me in only if the password matches exactly.

**[0:46]** Non-AI software operates entirely on instructions like this. It's the exact same logic that makes a calculator perform mathematical operations or a spreadsheet apply your formulas. This flowchart shows exactly what those rules look like in practice. The system waits for a condition, in this case an if statement checking if the password matches. When you enter your password, the program checks the rule. If the password matches, the software follows the green path to a specific action. Then, open the app. But if it doesn't match, the system follows the red path. It automatically executes the else command, showing you a message that the password is wrong and asking you to try again. Written rules return the same result every time. AI learns patterns from examples during training and uses those patterns to answer you.

**[1:34]** People still write the code that trains and runs AI, but they don't write each answer.

**[1:39]** This graphic uses a cooking analogy to show the difference between these two approaches.

**[1:44]** On the left, rule-based software is like a cooking robot following a recipe. Someone had to write out every single step. The robot measures the ingredients exactly, follows the instructions to the letter, and repeats the process. Same recipe, same result, every single time.

**[2:02]** On the right, AI is like a chef who learned from preparing hundreds of different dishes.

**[2:08]** Through training, this chef recognizes patterns. They know which ingredients work well together, how different cooking methods affect the food, and what substitutions make sense in a pinch. The chef doesn't need a recipe. By relying on learned patterns rather than strict rules, they can create entirely different dishes on the fly.

**[2:27]** Traditional software usually needs information entered in a specific structure. Think of a standard spreadsheet. The data has to be neatly organized into specific rows and columns for the program to understand it. That is structured data. AI, on the other hand, can work with unstructured data. You don't need to organize your input into clean fields. You can give it the messy information exactly as you have it, and the AI can help make sense of it. This graphic shows a side-by-side comparison of the exact same playlist in both formats. On the left, traditional software uses structured data. The table is perfectly organized. We have specific columns for song, artist, and play order.

**[3:11]** On the right, AI works with an unstructured, handwritten note. The data isn't arranged in a table. Instead, it uses visual cues. There is an arrow saying, start here, pointing to blinding lights, and a note to play this last, next to as it was. Notice that the song Shake It Off is just crossed out with a pen stroke. How does the AI notice skip a song that is clearly written right there on the page? AI can do this because during training, it learned patterns in handwriting, language, and visual clues like arrows and crossed out words. It uses those learned patterns to interpret the intent behind your messy notes. But relying on pattern recognition instead of rigid rules comes with the downside. Because the AI is interpreting unstructured inputs, its responses are harder to predict and inspect than a simple written rule like our password check.

**[4:03]** The AI system might miss a crossed-out song or misinterpret a handwritten arrow. It might look great, but still have mistakes.

**[4:14]** Different jobs need different tools. Choose the tool that fits the work.
