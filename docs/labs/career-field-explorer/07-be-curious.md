# Lab 7: Turn uncertainty into a next question

**Lesson:** Be Curious  
**Time:** 12–15 minutes  
**Starter:** `06-skills-that-matter-recovery.html` or the student's working file  
**Recovery:** `07-be-curious-recovery.html`

## Build

Let the student select one field that deserves another hour of investigation. Show
that field's unanswered question and low-risk next action in a clear next-step panel.
The language must describe exploration, not a career decision.

## Prompt to use with AI

> Add a final section called “Choose what to investigate next.” Let the user select
> one of the three fields. When selected, show that field's unanswered question and
> low-risk next action in a prominent panel. Make the selection changeable. The copy
> must say this is the next hour of exploration, not a career choice or recommendation.
> Keep the existing comparison and accessibility behavior intact.

## Test before finishing

- Selecting each field updates both the question and next action.
- The selection can be changed.
- No field is automatically selected as the best option.
- The next action is specific, small, and possible within a week.

## What this lab teaches

Curiosity is not collecting more information forever. It is turning the most useful
unknown into the next rep.
