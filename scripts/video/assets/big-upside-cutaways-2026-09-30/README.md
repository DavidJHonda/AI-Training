# Big Upside supporting scenes

Four purpose-generated images used in the user-approved v6 visual repair. Created with the built-in `image_gen` tool; exact prompts are in [PROMPTS.txt](PROMPTS.txt).

| Final asset | Video placement | Teaching role |
|---|---|---|
| scan-review.png | 2:03–2:11 | A clinician reviews an AI-flagged possible finding; the alert says “Review needed.” |
| antibiotic-lab.png | 2:25–2:30 | A computational candidate proceeds to laboratory testing. |
| menu-reading.png | 2:51–2:57 | A student uses a phone camera and audio output to access a printed menu. |
| weed-spraying.png | 3:17–3:22 | One active nozzle targets a weed between healthy crop rows. |

The first menu generation had an unsuitable phone orientation. A targeted image edit changed the viewpoint and camera-to-menu relationship; only the corrected image is used. These are illustrative scenes, not photographs documenting particular patients, research experiments, people or commercial products.

Build: `scripts/video/build_big_upside_v6.py`. The render applies a restrained 2.5% camera push without altering the image files. Current canonical course-board artwork remains in `course-assets/big-upside/`.
