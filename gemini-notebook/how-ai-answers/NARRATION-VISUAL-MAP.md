# How AI Answers: narration and visual plan

Review draft: [NARRATION-DRAFT.md](NARRATION-DRAFT.md). That file contains only the title and spoken narration so it can be read continuously without production directions. This plan is not an upload source.

The teaching progression is question context, first prediction, growing answer context, next prediction, and completion. Spoken bridges supply the connections that headings and spacing provide on the page. No new technical concepts are introduced.

## Review checks

- Read the narration without the pictures. The question mark, You, and him each have an explicit context explanation. “Last token” follows the current end of the growing sequence.
- Each spoken signpost immediately leads to its explanation or demonstration. The viewer is never asked to pause, guess, or answer.
- Probabilities are read once per new distribution, not again after selection. They are the existing authored example values, not new measurements.
- Pause locations are planned, not fixed durations. Set actual timing from the recorded delivery and word reveals.
- Keep the updated course boards and v20’s full blue demonstration layout. Use animation for changes over time; avoid keeping a board onscreen through unrelated narration.
- This is a written clarity pass, not a recording or listening review. No new video has been generated, and the active upload bundle has not been switched to this draft.
