# Lab 5: Turn the information into a comparison

**Lesson:** Creative Thinking  
**Time:** 12–15 minutes  
**Starter:** `04-people-skills-recovery.html` or the student's working file  
**Recovery:** `05-creative-thinking-recovery.html`

## Build

Convert the selected priorities into a comparison table with the three fields as
columns. Every cell needs a simple editable judgment. Also replace at least one
example field with a field or pathway the student had not seriously considered.

## Prompt to use with AI

> Give me three interface ideas for comparing three career fields through only the
> priorities the user selected. Keep each idea to two sentences and name the tradeoff.
> Do not code yet. After I choose, build that idea into the existing file. The result
> must remain readable on a narrow screen, preserve all field edits, and let the user
> change each comparison cell. Do not calculate a total or announce a winner.

## Test before finishing

- Only selected priorities appear in the comparison.
- All three fields remain visible.
- Changing one cell does not change another.
- The comparison works at phone width without cutting off content.

## What this lab teaches

AI can widen the options and suggest structures. The student chooses the better
angle and checks whether it actually works.
