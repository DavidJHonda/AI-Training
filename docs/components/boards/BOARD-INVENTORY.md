# Board Inventory

This is the first lesson-level classification under the current board system. It is
a decision map, not an instruction to rebuild every asset.

## Status definitions

- **Keep**: the current board language fits the teaching job.
- **Normalize**: preserve the concept and interior design; align only the shared
  shell, typography, spacing, dimensions, or canonical file pairing.
- **Redesign**: the current visual creates a comprehension, readability, consistency,
  or Notebook-compatibility problem.
- **Exception**: a worked example, story/evidence frame, opener, close, activity, or
  assessment that should not be forced into a primary family.
- **Defer**: classify again after the draft lesson or activity structure stabilizes.

## First retrofit priorities

The inventory does not justify a broad redesign. If a future retrofit is approved,
use this order:

1. Replace person-dependent shared/prep boards.
2. Correct outer canvas colors that do not match `#f7f4ff`.
3. Pair page and prep copies and eliminate stale duplicates.
4. Fix text that is unreadable at 880 px.
5. Normalize peer boards within the same sequence.
6. Redesign an interior only when comprehension improves.

Do not begin with utility formats, draft activities, or boards that already teach
clearly.
