## NAVIGATE THE FUTURE

# AI Agents

An AI agent is a computer program that doesn’t just answer questions like a regular ChatGPT or Claude. It can actually take action to finish a job for you.

Some agents are built into apps you already use. For example, we used the built-in coding agents in ChatGPT and Claude to build this course. We don’t know how to write code, so we described what we wanted in plain English. The agents found the right file, changed the code, and tested the layout. Then we reviewed the lesson closely to make sure the change worked as intended and the lesson was easy for students to follow.

Writing code is just one example. Across many kinds of work, AI agents are taking on tasks that people used to do themselves.

### Board 1: Agents Today

**Image file:** `rise-of-agents-uses.jpg`

![Agents Today](rise-of-agents-uses.jpg)

**Teaching content:**

Agents today.

Coding. People used to write code line by line, test it, and fix what broke. Now a coding agent can do all three.

Research. People used to visit competitors’ websites one by one to compare prices. Now an agent checks the same products across sites and builds a price comparison for the sales team.

Customer Service. People used to answer the phone and respond to customers in online chats. Now an agent can do both. When someone asks, “Where’s my package?” the agent can look up the order, check the tracking, and give them an update.

Office Work. People used to copy sales figures into a spreadsheet and make slides for the weekly meeting. Now an agent updates the numbers and prepares the slides for the team.

Agents can take a lot of busywork off people’s hands. But that raises a question many people are asking. If agents can do much of the work that makes up a job, what happens to the people doing that job today?

So how does an agent actually do the work?

### Board 2: How an Agent Works

**Image file:** `rise-of-agents-agent-loop.jpg`

![How an Agent Works](rise-of-agents-agent-loop.jpg)

**Teaching content:**

How an agent works, in four steps.

One, goal. You say what you want.

Two, plan. Break the goal into steps.

Three, act. Use a tool for the next step.

Four, check. Look at the result. Done, or not?

Not done? Go again. The loop returns to the plan.

The agent can finish, retry, or ask for help. You set the goal and judge the result.

## Closing Message

Agents do the work. The name on it is yours.
