# Preserved Transformer artwork

These two artwork crops retain the approved lamp/suitcase and cat/milk imagery
from `course-assets/transformer/transformer-resolves-meaning.jpg` at commit
`4a5f24f9`. They contain no lesson text and already include the approved color wash.

`render_transformer_context_revision.py` reuses them without adding another wash,
then typesets the revised examples using the existing Editorial board renderer.
The script owns the four revised Transformer boards as of 2026-10-10.
