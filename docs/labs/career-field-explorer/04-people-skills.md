# Lab 4: Build for a real person

**Lesson:** People Skills  
**Time:** 12–15 minutes  
**Starter:** `03-habits-for-the-road-recovery.html` or the student's working file  
**Recovery:** `04-people-skills-recovery.html`

## Human test first

Give the app to another student for two minutes. Do not explain it. Ask afterward:

1. What did you think this tool was asking you to do?
2. What felt unclear or missing?
3. What would matter to you when comparing fields?

Write down what the person actually said before changing the app.

## Build

Add a set of personal priorities. A student can choose up to four, see which choices
are active, and remove a choice. Use priorities such as meaningful work, stability,
creativity, helping others, hands-on work, flexibility, earning potential, and shorter
training.

## Prompt to use with AI

> Here is feedback from one real user: [paste the feedback]. Summarize the problem in
> one sentence before coding. Then add a “What matters to you?” section with eight
> priority buttons. Let the user select and deselect up to four. Show the selected
> state with more than color alone and explain the limit when they reach it. Keep the
> page responsive and do not rank the priorities.

## Test before finishing

- A priority toggles on and off.
- The active state is visible without relying only on color.
- A fifth selection is prevented with a clear message.
- The original tester can use the section without an explanation.

## What this lab teaches

The person using the app supplies information the builder and the AI cannot see.
