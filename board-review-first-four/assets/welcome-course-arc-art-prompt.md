# Welcome Course Arc — Artwork Prompt

Mode: built-in image generation

Use case: infographic-diagram

Asset type: supporting artwork for a 1600×900 educational course roadmap board

Input image: the existing Welcome-page course path was used as a content reference;
its card-grid layout was not reproduced.

Primary request: Create one wide horizontal strip containing five distinct, equally
sized, isolated vector-like mini-illustrations, left to right:

1. Work — a learner using an AI assistant purposefully at a laptop, suggesting
   productive collaboration.
2. Understand — an open-hood or cutaway view revealing layers, tokens, and learned
   patterns inside AI.
3. Avoid — a learner using a magnifying glass and shield to catch a misleading AI
   answer or warning.
4. Embrace — a learner confidently facing a changing future horizon with an upward
   path.
5. Build — a learner assembling practical tools or blocks into a rising staircase
   and personal advantage.

Style and composition: clean contemporary educational vector illustration matching
the existing course boards; bold simple shapes, light linework, modest depth, no
photography. Use exactly five columns, one centered illustration per column,
consistent scale and visual density, generous white space, and separable scenes for
vertical cropping.

Color palette: dark navy with course purple as the primary accent, plus restrained
blue, orange, teal, and pale lavender.

Constraints: white background; no text, headings, numbers, letters, labels, logos,
trademarks, watermarks, borders, dividers, cards, decorative captions, or extra
scenes.
