# Embeddings cutaway assets

`cans.png` was generated with the built-in image_gen tool for the user-approved mystery-drink and matching-profile scenes. `PROMPT.txt` preserves the exact prompt. The left product is Coke; the right is Pepsi. The RGBA canvas is 1774 × 887.

The build extracts each can by visible alpha bounds without altering the retained master. All taste labels, numbers and motion are rendered in `scripts/video/build_embeddings_v10.py`; no generated numerals are used.
