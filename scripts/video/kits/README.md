# Section production context

These section kits and status records were moved out of `Prompts/` on 2026-09-29.
They retain scene directions, source decisions, and review history still referenced
by the preparation registry and production tools. Dates and shipping claims describe
the recorded work; they do not certify the current lesson or video.

Follow [PREPARATION.md](../PREPARATION.md) for current preparation rules. Each
registered lesson owns its prompt and upload variants in `gemini-notebook/<slug>/`.
Its generated README and the registry define the current upload bundle. Older kit
entries can contain superseded teaching, board names, or generation methods. Legacy
prompts have been removed; lessons in the registry’s `needs_preparation` list require
fresh preparation from the current page. Do not reconstruct prompts from old notes. New lesson-specific notes belong beside that
lesson's prompt. Shared section context may stay here.
